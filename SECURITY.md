# Security and responsible disclosure

This repository contains synthetic data only and is not connected to a production system.

If you find a security issue in the code or a path that allows agent-facing logic to access evaluator-only truth, please open a private GitHub security advisory rather than a public issue. Do not include real credentials, customer data, or payment information in reports or test fixtures.

Fraud signals in this project are investigation cues, not proof. The agent is not authorized to block users, cancel orders, or make customer-impacting decisions.
